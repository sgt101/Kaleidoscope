================================================================================
LATEX WEB EDITOR - COMPLETE PROJECT
================================================================================

PROJECT OVERVIEW:
A modern, web-based LaTeX editor with file management, PDF preview, 
and AI assistant integration via Trifle.

================================================================================
CORE APPLICATION FILES (5 files)
================================================================================

1. index.html
   - Main HTML5 page structure
   - Three-pane layout (sidebar, editor, preview)
   - Chat interface at bottom
   - Loads CSS and JavaScript
   - 80 lines

2. styles.css
   - Dark theme styling (VS Code inspired)
   - Responsive grid/flexbox layout
   - Custom components and animations
   - Mobile breakpoints
   - 270 lines

3. app.js
   - Client-side JavaScript logic
   - File management (create, read, delete, upload)
   - Editor event handlers and auto-save
   - PDF compilation interface
   - Chat message handling
   - localStorage state management
   - 340 lines

4. server.js
   - Express.js backend server
   - LaTeX compilation endpoint (pdflatex)
   - Trifle AI chat endpoint
   - File upload handling
   - Mock response fallback
   - Error handling and logging
   - 280 lines

5. package.json
   - Node.js project metadata
   - Dependencies: express, cors, node-fetch
   - Dev dependencies: nodemon
   - npm scripts for start/dev

================================================================================
CONFIGURATION OPTIONS
================================================================================

Environment Variables (.env):
  PORT=3000                 - Server port
  NODE_ENV=development      - Environment
  TRIFLE_API_KEY=xxx        - AI API key (optional)
  TRIFLE_BASE_URL=xxx       - AI endpoint
  PDFLATEX_PATH=            - Custom pdflatex path
  UPLOAD_DIR=./uploads      - Upload directory
  MAX_FILE_SIZE=10485760    - Max upload (10 MB)

Customization Points:
  - styles.css              - Colors, layout, fonts
  - app.js                  - Editor behavior, defaults
  - server.js               - Compilation, API settings
  - index.html              - UI structure
